# GreenTomorrow — Travel-inspired sustainability website

A responsive 12-section single-page website concept using a premium travel/editorial visual direction: immersive landscape hero, oversized typography, cinematic imagery, clean navigation, destination-style content blocks and clear calls to action.

## Run
1. Extract the ZIP.
2. Open `index.html` in Chrome, Firefox or Edge.
3. Internet access is required for the Google Fonts and Unsplash photography used by the design.

## Sections (12)
1. Hero
2. Mission
3. Impact metrics
4. Programmes
5. Our journey
6. Featured campaign
7. Places / global vision
8. Photo gallery
9. Volunteer
10. Community stories
11. Donate / CTA
12. Footer and contact

## Four signature animated areas
- Hero: slow cinematic image zoom.
- Impact: animated count-up metrics when scrolled into view.
- Journey: timeline line reveal and staggered step reveals.
- Gallery: continuously moving image marquee (pauses on hover).
Additional scroll reveals and a story carousel are included.

## Before publishing
